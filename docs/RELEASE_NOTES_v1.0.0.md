账易首个开源版本，支持 Android 8.0 及以上。

- 记录常见和自定义周期订阅，正确处理月末、闰年与日期锚点。
- 看板与日历查看账单，按币种汇总本月付款及下月预计支出。
- 独立编辑单期账单或向后应用未来规则，保留历史付款和单期优惠。
- 本地保存、手动确认付款、主题与动态配色、完整 JSON 备份和恢复。

无账号、广告、支付接入和云同步。备份 JSON 未加密；恢复会替换当前数据。暂无通知提醒、汇率与合并导入。
